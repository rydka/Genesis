# Synthèse de la veille du 2026-11-06 : pipeline de génération 3D

Quatre veilles parallèles, une par étape du pipeline proposé par l'utilisateur. Détails et sources dans
les fiches `2026-11-06_1` à `_4`. Les licences citées ici sont à confirmer par l'audit de
`gardien-licences` ; rien n'est intégré avant la validation humaine dans `LICENSES.md`.

## Décisions de l'utilisateur (2026-11-06)

1. **nvdiffrast est exclu, y compris pour les tests internes.** Sa licence (« Nvidia Source Code License
   (1-Way Commercial) ») le limite à « research or evaluation purposes only ». Le rasteriseur de Kaolin
   (Apache-2.0) le remplace pour la cuisson des textures et pour l'optimisation par l'image.
2. **Ordre du pipeline** : l'optimisation par l'image passe **avant** la texture, pour ne pas casser les
   UV et la texture en déformant le mesh :

   ```
   générateur → nettoyage → optimisation par l'image → retopologie et UV → texture
   ```
3. Audit des candidats retenus confié à `gardien-licences`.

## Choix par étape

| Texture | Texturation de TRELLIS.2 | Projection Blender (témoin de fidélité) ; MV-Adapter | Cuisson UV avec Kaolin ; pas de RMBG-2.0 |

## Éliminés

- **TripoSG, Step1X-3D** : fichiers dérivés de Hunyuan sous licence Tencent excluant l'UE (en-têtes lus).
- **Hunyuan3D-Paint, MaterialMVP, MVPainter, UltraShape, BPT** : code ou base Hunyuan.
- **MeshAnything, FastMesh, EdgeRunner, LLaMA-Mesh, PartField, PartPacker, DSINE, Sapiens** : non commerciaux.
- **Tout ce qui impose nvdiffrast ou FLUX.1-dev** sans alternative (threestudio, Unique3D tel quel, UniTEX…).

## Articles proposés par l'utilisateur

- **FlexiCubes** (Shen et al., SIGGRAPH 2023) : retenu en tête de l'étape d'optimisation par l'image.
- **Mesh-Pro** (CVPR 2026) : pas de code publié ; à surveiller.
- **Yue et al. 2007** (optimisation de la qualité des triangles pour la CAO) : algorithme réimplémentable,
  priorité basse face aux bibliothèques retenues.
- **Unique3D** (NeurIPS 2024) : code MIT mais nvdiffrast, Stable Diffusion et poids sans licence claire ;
  l'idée d'ISOMER (reconstruction depuis des normales multi-vues) est réutilisable sur Kaolin.
